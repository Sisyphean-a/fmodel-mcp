# 领域上下文

本工作区要解决的是：在本机只读地观察黑神话悟空资源，为逻辑 MOD 研究提供可追溯的静态资产、文本、符号、依赖和导出证据。当前只有一个工作区级语义边界，没有证据表明存在更窄的领域上下文；后续若出现不同语义所有者，再拆分到 `contexts/`。

## 作用域

- `workspace`：当前全部领域语言和跨功能不变量由本文件拥有。
- `package:fmodel-mcp`：实现映射见 [架构包页](../architecture/packages/fmodel-mcp.md)；包是实现边界，不自动产生新的领域上下文。

## 通用语言

**逻辑 MOD**：以静态资源研究为目的，定位资源、读取字段和符号、追踪包级依赖并导出证据的 MOD 工作；不等于运行时注入或安装行为。
_避免_：把静态分析结果称为已验证的运行时 Hook、调用路径或业务效果。

**游戏配置**：一份准备应用到本地解析会话的配置；配置存在不代表已经成功挂载。
_避免_：把配置文件、会话状态和挂载成功混为一谈。

**会话（Session）**：一个 Worker 进程及其唯一配置、Provider 和目录快照的运行身份。

**容器（Archive）**：一个 pak 及其挂载诊断；密钥 GUID 不是容器唯一身份。

**物理条目（Entry）**：某个容器中某一路径的一份文件记录，可被其他容器覆盖。

**有效文件（EffectiveFile）**：按实际 `ReadOrder` 为某一路径选出的文件；同级最高顺序相等时没有可推断的赢家。

**包（Package）**：`.uasset` 或 `.umap` 及其实际存在且应保持来源一致的伴随文件。

**对象（Object）**：包内 export，具有 Outer 链；不等于包，也不等于游戏运行时实例。

**符号（Symbol）**：从类、函数或属性观察到的静态元数据。

**文本身份**：文本值与其来源位置、namespace/key、tableId、语言和解析状态组成的可追溯身份；显示文本本身不是身份。

**索引快照（Snapshot）**：某种索引对一个声明范围的一次构建结果；查询只读取已发布快照。

**覆盖率（Coverage）**：声明范围内已扫描、成功、失败、跳过和未知的情况；不代表恢复了完整游戏语义。

**业务 ID**：游戏表格字段或行名等由结果消费者解释的业务标识；本地化 key 不是天然业务 ID。

## 稳定规则

- 本工具是离线静态研究工具：游戏文件只读，输出必须保留来源和完整性；不注入进程、不执行游戏代码、不修改/安装 MOD，不自动猜 AES、取得 usmap 或联网修复依赖。
- 物理重复与有效文件必须分开表达；索引默认基于有效文件。实际 `ReadOrder` 决定覆盖，同级冲突必须显式报告，不能靠枚举顺序或空结果掩盖。
- 文本检索保留“文本 → 本地化身份 → 表格行/字段”等证据链；相同显示文本、同名对象或同名业务字段不能在无身份依据时自动合并。
- 外层成功、扫描覆盖率和对象/脚本完整性是三个独立维度；无法解析的必需信息要以失败或 partial 状态出现，不能把“不知道”当成没有结果。
- 包级 import 关系只说明静态包依赖，不等于完整对象引用图、运行时调用图或可用 Hook 名称；业务 ID 不由工具推测补齐。
- v1 只对 pak 建立支持边界；发现 IoStore（utoc/ucas）时给出不支持诊断，不把它冒充为已挂载能力。
